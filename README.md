# Christmas Comfort website

A responsive, pastel-themed multi-page website inspired by the reference site.

## Pages
- `index.html` — Home
- `who-we-are.html` — Who We Are
- `mission.html` — Our Mission
- `vision.html` — Our Vision
- `products.html` — Cushion Gallery

## How to view
Open `index.html` in a browser. Keep `styles.css` and the `assets` folder in the same directory structure.

## Publish with GitHub Pages
Upload all files and the `assets` folder to your repository. In GitHub, go to Settings → Pages and select the branch/folder you want to publish.
